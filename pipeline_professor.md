Déjà commencez par créer un projet Unity commun. 
Essayez de travailler avec des scènes simples. 

- Commencez par créer le Player Controller pour le joueur.
- Créez le script d'interaction avec des prefab d'objet à récupérer
- Vous pouvez y ajouter une réduction de la taille si vous voulez.
- Ensuite il faut ajouter le déplacement de ces animaux avec 4des nav mesh agent et nav surface.
- Il faudra ajoutez un script inventaire pour garder les objets possédés
- Créez le script de transition de scènes pour garder la liste en mémoire pour pas qu'elle soit détruite.
- Ensuite il vous faudra la mécanique inverse de dépôt d'un objet présent dans la liste 
- Vous devez créer le déplacement d'objet par exemple avec du grabbing  
- Ensuite vous pourrez créer le script avec des trigger box et collider pour tester si l'objet en question est le bon.  
- Ajoutez le script de timer pour gagner ou perdre du temps
- Enfin ajoutez la scene or menu, qui donne les animaux/objets à chercher et mémoriser. Cependant il faut que vous gardiez la liste en mémoire 
- Vous pourrez alors créer le script qui déclenche les scripts d'humour
- Finalement vous pouvez essayez de créer les contrôles avec téléphone
